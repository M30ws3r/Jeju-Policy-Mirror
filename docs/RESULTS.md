# 결과 설명서 — 2024년 8월 제주 버스 노선 개편 검증

공개 URL: https://jeju-policy-mirror.vercel.app · 재현: `cd backend && python scripts/run_bus_cases.py` (결과는 `backend/output/*.json, *.pdf`)

## 1. 무엇을 확인했나

제주도는 2024년 8월 1일 85개 노선을 조정하고 버스 75대를 감차했다. 에이전트에게 "이 개편 뒤 해당 노선 이용객이 얼마나 변했나"를 5개 사례로 물었다. 에이전트는 사례마다 시행 전 흐름이 비슷한 비교 노선 8개를 고르고, 이중차분으로 효과를 추정한 뒤, 10가지 점검을 통과한 만큼만 주장한다.

같은 12개월 제주 전체 카드 소비(전년 같은 달 대비): 도민 −5.3%, 내국인 관광객 −8.9%, 외국인 관광객 +8.8%.

## 4. 어떻게 읽나

- **단순 비교가 과장하는 정도**: 감차 노선은 단순히 보면 36% 줄었지만, 개편과 무관하게 섬 전체 이용이 함께 줄었다. 비교 노선과 견주면 약 20% 감소로 추정되고, 신뢰구간이 0을 포함해 "뚜렷한 감소"라고 단정할 수 없다.
- **판단 보류(C)**: 326·325번과 311번은 시행 전부터 비교 노선과 다른 방향으로 움직였다. 이런 경우 추정치를 아예 지우고 관측된 사실만 보고한다. 311번은 원래 추세만 연장해도 −24.9%가 설명된다.
- **승객 이동**: 352번 폐지 후 351번과 합산하면 감소가 −4.6%로 작아져, 통합 노선이 승객을 상당 부분 흡수한 것과 양립한다.
- **관광 수요 착시**: 도민과 관광객의 소비 변화 폭이 3.6%p 달라, 관광객이 많이 타는 노선과 도민 노선이 정책과 무관하게 다르게 움직였을 수 있다. 모든 사례에 주의를 붙이고 판정문에 수치를 적었다.

## 5. 한계

- 조정된 85개 노선 전체 목록을 확보하지 못해(사례표 34개), 비교 노선에 조정 노선이 섞였을 수 있다(전 사례 '순도 주의'). 신뢰구간이 넓은 주된 이유다.
- 버스는 4일 간격 표본이며 승차·일반·카드만 집계한다. 2026.11.14부터 허브 API 502 오류로 추가 수집이 멈췄다.
- 카드 점검은 제주 전체 합계 기준이며 노선–읍면동 연결은 아직 없다. 제공처 유의사항의 '도민 소비 제외' 문구와 달리 파일에 도민 구분이 있어 확인이 필요하다.
- 관측 자료 분석이므로 무작위 실험 수준의 인과 증명이 아니다. 동시기 다른 사건(요금 변화, 도로 개통 등)은 자동으로 구분하지 못한다.

## 6. 엔진 검증

자동 테스트 33건(`cd backend && python -m pytest -q`). 정답을 심은 합성 데이터에서 효과(지역 약 +5%, 노선 −20%)를 구간 안에 복원하고, 자체 추세가 있는 대상은 C등급으로 강등하며, 수요 점검은 A를 B로만 낮추고 추정치는 바꾸지 않음을 확인한다.
