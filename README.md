# Jeju Policy Mirror - 제주 지역정책 효과 검증 에이전트

"2024년 8월 감차한 노선의 이용객은 실제로 얼마나 줄었나?" 같은 질문에,
비교 노선을 스스로 고르고 → 시행 전후를 비교하고 → 계절성·기존 추세 같은 다른 설명을 점검한 뒤 →
**정책 효과라고 말해도 되는지 등급(A/B/C)을 매겨** 정책 검토 PDF 로 내보내는 AI Agent 입니다.

비교 조건이 충족되지 않으면 인과효과 추정치를 결과에서 **삭제**하고 관측된 사실만 보고합니다(C 등급).

> 2026 제주 AI·빅데이터 활용 AI Agent 개발 챌린지 출품작.
> 화면 위쪽 '실제 제주 정책 검증'은 제주데이터허브 실데이터, 아래쪽 '자유 질문 시연'은 **합성 샘플**(실제 수치 아님)입니다.

## 1. 구성

```
backend/   Python · FastAPI · 에이전트
  app/main_v2.py            실행 진입점 (기존 main.py + 실데이터 사례 API)
  app/agent/pipeline_bus.py 노선 단위 정책 검증 (실데이터)
  app/agent/pipeline.py     지역 단위 정책 검증 (합성 샘플 시연)
  app/agent/stats.py        통계 엔진 (NumPy 자체 구현)
  scripts/                  수집·집계·일괄 실행 스크립트
  data/policy_cases.json    정책 사례표 (운영자 관리)
frontend/  TypeScript · React · Vite
docs/      DATA_SPEC.md(데이터 활용 명세) · SECURITY_OWASP.md(보안 분석) · DEPLOY.md(배포)
```

## 3. 설치와 실행 (센터 PC / 로컬, Windows 기준)

필요: Python 3.10 이상, Node.js 20 이상.

```bat
:: 1) 백엔드
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python scripts\gen_keys.py            :: 출력된 4줄을 .env 에 붙여넣기
python scripts\gen_dev_cert.py        :: 로컬 HTTPS 인증서
uvicorn app.main_v2:app --port 8000 --ssl-certfile certs\localhost.pem --ssl-keyfile certs\localhost-key.pem

:: 2) 프런트엔드 (새 창)
cd frontend
npm ci
npm run dev                           :: https://localhost:5173
```

자체 서명 인증서라 브라우저가 처음 한 번 경고를 띄웁니다(로컬 전용).

## 4. 실데이터 준비 (버스 614)

API 키는 제주데이터허브에서 발급받아 **실행할 때 입력**합니다. 파일·코드·제출물에 저장하지 않습니다.

```powershell
# 저장소 최상위 폴더의 상위에서 실행 (하루 쿼터 1,000건 → 여러 날에 나눠 실행, 이미 받은 날짜는 건너뜀)
powershell -ExecutionPolicy Bypass -File "Jeju Policy Mirror\backend\scripts\fetch_bus_skip.ps1" -Start 20221201 -End 20250731 -MaxCalls 950
```

```bat
cd backend
python scripts\build_bus_monthly.py   :: bus_days\*.csv → data\real\bus_monthly.csv
python scripts\run_bus_cases.py       :: 정책 사례 일괄 분석 → output\*.json, *.pdf (선택)
```

`bus_monthly.csv` 가 생기면 화면의 '실제 제주 정책 검증' 영역이 활성화됩니다.

- `fetch_bus.ps1`: 원래 수집기 (오류가 나면 그 자리에서 멈춤)
- `fetch_bus_skip.ps1`: 오류 날짜를 건너뛰고 계속 (연속 3개 실패 시 서버 장애로 보고 멈춤)
- `check_bus_coverage.ps1`: 월별 제공 건수 확인

## 5. 테스트


공개 URL: https://jeju-policy-mirror.vercel.app (절차는 `docs/DEPLOY_VERCEL.md`). 화면은 실데이터만 씁니다: 위쪽은 정해진 정책 사례 5건, 아래쪽은 노선 번호·시행 연월이 들어간 자유 질문(`POST /api/ask`). 합성 샘플 화면(`App.tsx`)은 개발·테스트용으로만 남겨 두었습니다.

## 7. 사용자 매뉴얼

1. **실제 정책 검증**: 화면 위쪽의 사례 버튼을 누릅니다.
2. 결과 맨 위 등급을 봅니다.
   - **A 준실험 근거 충족**: 비교 조건 점검을 모두 통과. 추정치를 근거로 인용할 수 있습니다(한계 병기).
   - **B 잠정 추정**: 주의 항목이 있습니다. 점검표의 '주의' 줄을 확인하고 단정하지 않습니다.
   - **C 연관성만 보고**: 비교 조건 미충족. 효과 추정치는 제공하지 않고 관측된 변화만 보여 줍니다.
3. '관측된 사실' 표에서 시행 전후 하루 평균 승차 인원을, 그래프에서 비교 노선과의 흐름 차이를 봅니다.
4. 'PDF 내려받기'로 정책 검토 보고서를 저장합니다.
5. **자유 질문 시연**(아래쪽)은 합성 샘플로 에이전트의 질문 해석·판정 과정을 체험하는 곳입니다.

## 8. 에이전트 구조

| 단계 | 하는 일 | 자율 판단 범위 |
|---|---|---|
| 질문 해석 | 대상·시행월·정책 종류 확인 (사례표 또는 문장 해석) | 모르면 추측하지 않고 되묻는다 |
| 데이터 구성 | 세부 경로→노선번호 합산, 월별 하루 평균(평일·주말 가중) | 표본일 3일 미만인 달·결측 노선 제외 |
| 비교 노선 선정 | 조정되지 않은 노선 중 시행 전 흐름 유사도 상위 8곳 | 선정 점수 공개 |
| 추정 | 로그 이중차분 + Newey–West + 플라시보 노선 산포로 구간 보수화 | — |
| 검증 | 관측 기간, 비교 노선 수, 평행추세, 가짜 시행일, 추세 연장, 계절 민감도, 노선 플라시보, 표본·요일 민감도, 비교 노선 순도, 지역 소비 수요(카드) | — |
| 게이트 | 필수 실패 → C(추정치 삭제) / 경고 → B / 전부 통과 → A | 규칙으로만 결정, LLM 관여 없음 |
| 보고 | 판정문·관측 사실·그래프·점검표·한계 → 화면 + PDF | — |

## 9. 실데이터 결과 (2026-11-13 수집분 기준, 표본 204일)

| 사례 | 등급 | 시행 전후 변화 | 비교 노선 대비 추정 |
|---|---|---|---|
| 감차 노선 묶음 (211·212·221·222·311·800번) | B | −35.9% | −19.8% (95% 구간 −49.4 ~ +27.0) |
| 326번 폐지 + 325번 통합 합산 | C | −36.3% | 추정 안 함 (사전 추세 불일치) |
| 352번 폐지 + 351번 통합 합산 | B | −14.6% | −4.6% (−39.8 ~ +51.1) |
| 521번 폐지 + 520번 통합 합산 | B | +5.9% | +27.7% (−19.4 ~ +102.3) |
| 311번 단독 | C | −29.6% | 추정 안 함 (사전 추세 불일치) |

전체 노선 하루 평균 승차 인원은 같은 기간 −11.9%. 같은 기간 제주 전체 카드 소비는 도민 −5.3%, 내국인 관광객 −8.9%(전년 같은 달 대비)로, 두 집단의 변화 폭 차이(3.6%p)가 커서 모든 사례에 '지역 소비 수요' 주의가 붙습니다. 조정된 85개 노선의 전체 목록을 확보하지 못해 비교 노선에 조정 노선이 섞였을 수 있으며(모든 사례 '주의'), 이 때문에 구간이 넓습니다. 수집이 더 진행되면 숫자가 바뀔 수 있습니다.

## 10. 오류·제약사항

- **표본 수집**: 하루 쿼터(1,000건) 때문에 4일 간격 표본으로 수집했습니다. 허브에 자료가 없는 날도 있습니다(확보분의 약 11%).
- **집계 범위**: '승차·일반·카드'만 집계합니다. 현금·청소년·어린이·환승 제외.
- **노선번호**: '251-1'처럼 번호에 '-'가 든 노선은 본 노선과 합쳐집니다.
- **조정 노선 목록 불완전**: 공개 보도로 확인한 34개 노선만 비교 후보에서 뺐습니다. 전체 목록을 `data/policy_cases.json` 에 넣고 `affected_list_complete` 를 `true` 로 바꾸면 정확도가 올라갑니다.
- **동시기 다른 사건**(요금, 정류소, 도로, 행사)은 자동으로 구분하지 못합니다.
- **허브 서버 오류**: 2026-11-14 수집 중 502 오류가 반복되었습니다. `fetch_bus_skip.ps1` 로 재시도합니다.
- **LLM 연동·Vercel 배포**: 코드는 있으나 실서버로 시험하지 않았습니다.

## 11. AI 도구·외부 자원 명시 (대회 규칙)

- **개발에 사용한 AI**: Anthropic Claude (코드·문서 초안 작성). 참가자가 검토·실행 확인.
- **실행 시 AI 모델**: 기본 없음(규칙 기반). 선택 시 Ollama 로컬 모델 또는 OpenAI 호환 API — 질문 해석 보조와 문장 다듬기에만 사용.
- **외부 서비스 의존성**: 센터 실행 시 없음(수집 시에만 제주데이터허브 API). 공개 웹 배포 시 Vercel, Neon.
- **오픈소스**: FastAPI, SQLAlchemy, pandas, NumPy, reportlab, bcrypt, PyJWT, cryptography, nh3, React, Vite, zod. 글꼴 나눔고딕(OFL 1.1).
- **외부 데이터**: 없음 (필수 데이터 2종 + 언론 보도를 근거로 작성한 정책 사례표).
